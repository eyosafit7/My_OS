## Hi there, I'm Eyosafit Samuel

Liqlaqo OS is a web-based operating system built with HTML, CSS, and vanilla JavaScript. It can run in the browser 

I used the macOS and Windows interfaces as models and worked on my own interface. to close you can click the red dot that are placed in top right corner of each app window. to open you can click the corresponding name to that app and you can drag one element and move it to wanted place

I built the calculator app by watching my phone calculator as reference. I simply built it myself from scratch (brick by brick).

I built the notebook app from scratch.You can type anything in it, save, load, and update your notes. if you want to see what files are saved go to setting and click refresh you won't miss it. to delete you can go to settings then to  data and privacy and click clear notebook data.

I also included music app because my cousin asks me to do it. i tried to make it more interactive with background if you click one file it will automatically changes the background, the picture, and the name.

In settings, you can choose the wallpaper from three distinict picture that are available by default. those are pikachu, samurai and spiderman. And also let's you see what files saved by refreshing to get updated information and also clear notebook data if you know the corresponding password to that file.

I built clock and date that makes the project more real operating system.

To build this project i used html, css, javascript, and git  for basic component, style,functionality, and version control respectively.if you wanna see it right now, you can click the link here ==> [Open Liqlaqo OS](https://eyosafit7.github.io/MY_OS/)
